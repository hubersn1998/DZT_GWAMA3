# DZT_GWAMA3
The script used for the third GWAMA for DZT from the preprint/publication: 

This repository includes:
- Three scripts that were included in the SOP of the Twinning Genetics Consortium, called Script_step_0.sh, Script_step_1.sh, and Script_step_2.sh.
- The EasyQC script used to perform QC on each of the summary statistics provided by the contributing cohorts, called EasyQC_DZT_GWAMA3.ecf
- The METAL script used to perform the overall GWAS meta-analyses on the human data, called Metal_DZT_GWAMA3.txt
- The folder human_cattle_meta_analysis that included the script that was used to perform the cross-species analyses. These scripts were prepared by Dr Marijn Schipper (https://github.com/Marijn-Schipper).
